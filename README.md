# Excel to PDF 高速並列一括変換ツール (ExcelToPDF)

任意のフォルダ内にある複数のExcelファイル（`.xlsx`, `.xls`, `.xlsm`, `.xlsb`）を並列処理とオフィス最適化技術を用いて、超短時間で一括PDF化するデスクトップアプリケーション（GUI / CLI）です。

---

## 📌 プロジェクトの4大骨子

### ① 目的
大量のExcelファイルをボタン一つ、あるいは1行のコマンドで、極めて短時間に美しく高品質なPDFファイルへと一括変換できる、堅牢かつ直感的なツールを提供すること。

### ② 現状の課題
- **変換速度の極端な遅延**: 通常のVBAマクロやPowerShellスクリプトで変換を行うと、1ファイルごとにExcelの初期化、シートの再計算、外部データリンクの確認ダイアログ、ネットワークプリンタへの問い合わせ、画面再描画などが走り、**1ファイルあたり約15〜20秒**を要する。
- **大量バッチ処理の破綻**: 例えば100ファイルのExcelを変換する場合、逐次処理では25〜35分以上も処理待ちが発生し、途中でポップアップが出ると処理が停止してしまう。
- **再利用・設定管理の不足**: 単純なスクリプトでは、フォルダ階層の保持、上書きポリシー、並列数の調整、処理履歴の記録などの管理が煩雑。

### ③ 課題解決方法
- **マルチプロセス並列処理**: CPUコア数に応じた複数ワーカープロセス（`ProcessPoolExecutor`）を立ち上げ、並行して変換を実行。
- **Office / COM オートメーションの徹底的な軽量化**:
  - 各ワーカー内でExcelインスタンスを立ち上げて使い回し、プロセス起動オーバーヘッドを削減。
  - `ScreenUpdating = False`（画面描画オフ）
  - `DisplayAlerts = False`（警告ポップアップ停止）
  - `EnableEvents = False`（マクロイベント停止）
  - `AskToUpdateLinks = False`（外部リンク更新停止）
  - `Calculation = xlCalculationManual`（再計算停止）
- **マルチエンジン & クロスプラットフォーム対応**:
  - Windows環境: Microsoft ExcelネイティブCOM (`pywin32`) を活用した高速並列化。
  - Mac / Linux / 外部PC環境: LibreOfficeのヘッドレス変換をユーザープロファイル隔離並列モードで完全サポート。
- **CRUD対応の設定・履歴マネージャー**:
  - 変換プロファイル（プリセット）の作成(C)・参照(R)・編集(U)・削除(D)。
  - 変換履歴ログの自動記録(C)・閲覧(R)・メモ編集(U)・削除(D)。

### ④ 提供できる価値
- **所要時間を最大 90% 以上削減**: 1ファイルあたり15〜20秒かかっていた変換時間を、1ファイルあたり約0.8〜1.5秒程度まで短縮。並列4〜8コア動作により、100ファイルの変換がわずか数分で完了。
- **業務の完全自動化**: 画面ポップアップで止まらない安定性と、CLIによる定期タスク（タスクスケジューラ / cron）連携の実現。
- **直感的なGUIと履歴管理**: PCに不慣れなユーザーでもGUIからフォルダを選んで並列スライダーを動かすだけで瞬時に変換完了。

## 🚀 クイックスタート

### 動作環境
- Python 3.10 以上
- Windows (Microsoft Excel インストール推奨) または macOS / Linux (LibreOffice インストール推奨)

### インストール方法
```bash
# 依存関係のインストール (uv推奨)
uv pip install -r requirements.txt
# または標準pip
pip install -r requirements.txt
```

### 起動方法

#### 1. GUIモード (デスクトップ画面)
```bash
python main.py
```

#### 2. CLIモード (コマンドライン)
```bash
# 基本的な一括変換
python main.py --cli --input "C:/Data/Excels" --output "C:/Data/PDFs"

# 並列数を指定してサブフォルダも再帰変換
python main.py --cli --input "./excels" --workers 6 --recursive

# プロファイル一覧表示
python main.py --cli --list-profiles
```
